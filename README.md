# Python Server Health Checker

## Project Overview

A beginner Python project that simulates basic server health checks using sample server data.

## Features

- Stores server information using lists and dictionaries.
- Checks simulated server reachability.
- Classifies CPU utilization as NORMAL, WARNING, or CRITICAL.
- Uses functions to organize reusable logic.
- Skips CPU checks for unreachable servers.

## Concepts Practiced

- Variables and data types
- Lists and dictionaries
- Conditional statements
- For loops
- Functions, parameters, arguments, and return values
- Git and GitHub version control

## How to Run

Run the following command from the project directory:

```bash
python server_health_checker.py
```

## Limitations

This is a learning project that uses simulated data. It does not connect to real servers or retrieve live CPU metrics.
